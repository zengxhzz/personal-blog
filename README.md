# 个人博客

个人前端作品集。首页通过滚动展示 Gentle Diary 的项目概览、写作界面和主题设计，手机上可以左右滑动图集。项目详情记录设计调整，关于页介绍搭建网站时的开发实践。

[访问博客](https://zengxhzz.github.io/personal-blog/)

## 本地查看

克隆仓库后，在浏览器中打开 `index.html`。
